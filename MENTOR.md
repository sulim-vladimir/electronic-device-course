# Для наставника

Як підготувати учня до курсу, перевіряти його кроки і підтримувати курс.

## Перед стартом

1. Додай учня як учасника репозиторію: **Settings → Collaborators → Add people**.
2. Переконайся, що в `main` лежить актуальна версія (`pcb/`, `firmware/`, `index.html`, `submissions/`).
3. Домовтеся про Telegram-чат для питань і про те, як часто ти перевіряєш pull request.
4. Перший pull request (кроки 00–02) варто перевірити особливо уважно: це перше знайомство з процесом, і твої коментарі задають рівень для всіх наступних кроків.

## Як перевіряти крок

1. На GitHub відкрий **Pull requests** і вибери «Крок NN: ...».
2. Вкладка **Files changed**:
   - Прочитай `submissions/step-NN.md`. Список «Прийнято, коли» внизу — це те, що треба перевірити.
   - Відкрий скріншоти і звіт DRC (`step-NN-drc.rpt`), якщо крок їх має.
   - Файли KiCad показуються як довгі текстові зміни. Читати їх рядок за рядком не потрібно: дивись скріншоти і звіт DRC або відкрий гілку в KiCad сам:
     ```
     git fetch
     git switch step-NN
     ```
3. Натисни **+** біля будь-якого рядка, щоб залишити там коментар.
4. Заверши через **Review changes**:
   - **Approve**, потім **Merge pull request** і **Delete branch**: крок прийнято.
   - **Request changes** з коротким списком, що виправити: крок повертається на доробку.

## Кроки, де потрібне твоє рішення

Кроки з позначкою **Перевірка наставника** стосуються грошей, безпеки або великих рішень. Обговоріть їх у pull request, перш ніж схвалювати:

- **Що ти будуєш?** — хто покупець, де він бачить дані (сервер, Telegram-бот), цілі з числами.
- **Інструменти, бюджет і терміни доставки** — що купувати і за чий рахунок.
- **Як заряджатиметься акумулятор?** — зокрема, щоб Li-ion не заряджався нижче 0 °C.
- **Вибери корпус** і **Де буде термометр?**
- **Фінальна перевірка і замовлення** — ти платиш і оформлюєш замовлення на JLCPCB.
- **Від прототипу до невеликої серії** — продаж через дорослого, податки, гарантія, правила для електроніки з Wi-Fi і літієвими акумуляторами.

## Як підтримувати курс

- Увесь курс — це один файл `index.html` у головній папці. Посилання на кроки в тексті записані як `{{stepId}}`, тож номери кроків оновлюються самі, коли додаються нові кроки.
- Після додавання кроків запусти `node tools/make-submissions.js`. Він створює файли відповідей для нових кроків і ніколи не перезаписує наявні. Якщо крок отримав новий номер, його старий файл лишається з попереднім номером — перейменуй його за потреби.
- Шаблон pull request лежить у `.github/pull_request_template.md`.
